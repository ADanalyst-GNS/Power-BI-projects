 Twitter Analytics Dashboard using Power BI

 Overview

This project is an interactive Power BI dashboard built to analyze Twitter engagement and performance metrics. It demonstrates data cleaning with Power Query, data modeling, DAX calculations, and interactive visualizations to extract meaningful insights from Twitter data.

 Objectives

* Analyze tweet engagement metrics.
* Compare interactions across tweet categories.
* Evaluate the impact of media and app opens.
* Identify monthly engagement trends.
* Find the top-performing tweets.

 Tools Used

* Microsoft Power BI Desktop
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

 Dashboard Overview

The dashboard consists of six report pages:

1. Tweet Interaction Breakdown by Category
2. Engagement Rate Comparison (With vs Without App Opens)
3. Media Interaction by Day of the Week
4. Replies, Retweets & Likes Comparison
5. Monthly Engagement Rate Trend
6. Top 10 Tweets by Total Engagement

Key Features

* Data cleaning and transformation using Power Query
* Date Table and data modeling
* DAX calculated columns and measures
* Interactive charts and filters
* Time-based visual visibility
* Top N analysis
